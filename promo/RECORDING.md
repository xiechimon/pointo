# 宣传片实拍：分镜和录制说明

这份说明给你本人用，也可以直接交给 Mac 上的 Agent 照做。宣传片里的「演示」段（第 8–22 秒）和「交付修复」段（第 22–24 秒）会换成这里录到的真实画面。

整个故事只有一件事：**设置页的「保存更改」按钮点了没反应 → 用 Pointo 录下来指给 AI 看 → AI 读录制、改代码 → 再点一次，好了。**

---

## 0. 准备（一次性，约 10 分钟）

### 演示项目

```bash
sh promo/demo-app/setup.sh
```

```bash
cd ~/Code/acme-console && python3 -m http.server 5173
```

浏览器打开 `http://localhost:5173`。项目里故意留了一个 bug：保存按钮点了没有任何反应，不要提前修。

### 桌面

- 系统设置 › 桌面与程序坞：打开「自动隐藏和显示程序坞」。
- 隐藏桌面图标（Finder › 设置，或者 `defaults write com.apple.finder CreateDesktop false && killall Finder`，录完改回 `true`）。
- 墙纸换成纯色，浅灰或米白（系统设置 › 墙纸 › 颜色）。
- 打开勿扰模式，关掉微信、QQ、邮件等所有会弹通知或带私人内容的应用。
- 菜单栏只留 Pointo、Wi-Fi、电池、时间。其他图标可以按住 ⌘ 拖出去，或者用 Ice / Bartender 隐藏。
- 浏览器用一个干净的配置：没有书签栏、没有插件图标、只开一个标签页，窗口大小约 1280×800，放在屏幕正中。
- 终端用 Ghostty 或系统终端，字号调到 18 以上，浅色主题；窗口约 1100×700。

### 两路同时录

Pointo 自己的 `recording.mp4` 是给 AI 看的，可能不带 Pointo 的胶囊和红色笔迹。宣传片需要看到这些，所以要**另开一路整屏录制**：

- 用 QuickTime Player › 文件 › 新建屏幕录制（或 `⌘⇧5`），录**整个屏幕**，选项里关掉「显示鼠标点击」（Pointo 自己会画点击波纹）。
- 如果有 OBS 更好：1920×1080 以上、60 fps、码率 40 Mbps 以上。
- 先开整屏录制，再开始下面每一镜，每镜之间不用停，剪辑时我来切。

---

## 1. 分镜

时间是建议节奏，不用卡表。**慢一点比快一点好**，剪辑时可以加速，但不能减速。每个动作前后都停 1 秒。

### 第 1 镜：发现问题（约 6 秒）

| 时间 | 画面和动作 |
|---|---|
| 0–2 s | 浏览器里是 Acme 设置页。鼠标从右下慢慢移到「保存更改」。 |
| 2–3 s | 点「保存更改」。什么都没发生。 |
| 3–5 s | 再点一次，停 1 秒。（这两下是「没反应」的证据。） |

### 第 2 镜：用 Pointo 录（约 15 秒，最重要）

| 时间 | 画面和动作 | 说的话（普通话，正常语速） |
|---|---|---|
| 0 s | 按 `⌥⇧S` 开始录（用聚焦窗口模式，对准浏览器窗口）。胶囊弹出。 | |
| 1–2 s | 停一下，让胶囊动画完整播完。 | |
| 2–5 s | 鼠标移到「保存更改」，点一下。 | 「这个保存按钮点了没反应。」 |
| 5–8 s | **按住 `⇧`**，围着「保存更改」慢慢画一个圈，画完松开。 | 「就这里。」 |
| 8–11 s | 鼠标移到右上角（toast 应该出现的位置），按住 `⇧` 画一个小框。 | 「点完应该在右上角提示已保存。」 |
| 11–13 s | 停 1 秒。 | |
| 13 s | 再按 `⌥⇧S` 结束。等胶囊显示处理完成、投递到 `acme-console`。 | |

注意：

- 圈要画大一点、慢一点（1 秒左右画完），不要涂鸦式来回画。
- 说话离麦克风近一点，环境安静。
- 如果某一下没做好，直接再录一次整个第 2 镜，留最好的那条。

### 第 3 镜：AI 修复（约 20 秒）

在 `~/Code/acme-console` 里打开终端，启动 Claude Code（或你常用的 Agent），输入：

```
看一下 .pointo/latest 里我刚录的，帮我修好
```

- 让它自然地读 `summary.md`、看图、改 `app.js`。不要提示答案。
- 等它改完并给出说明后停 2 秒。
- 如果它第一次没修对，整镜重录（可以先 `git checkout app.js` 还原）。

### 第 4 镜：修好了（约 5 秒）

| 时间 | 画面和动作 |
|---|---|
| 0–1 s | 切回浏览器，`⌘R` 刷新。 |
| 1–2 s | 鼠标移到「保存更改」，点一下。 |
| 2–4 s | 右上角出现「✓ 已保存」。停 2 秒。 |

### 第 5 镜：补拍特写（可选，各 3 秒）

- 菜单栏里 Pointo 的图标，鼠标悬停一下。
- 在 Finder 里打开这次的 `.pointo` 目录，选中 `contact-sheet.png` 按空格预览。

---

## 2. 录完发我

1. 整屏录制的视频文件（第 1–5 镜，一个或多个文件都行）。
2. 第 2 镜生成的那个 `.pointo` 目录整个打包（含 `recording.mp4`、`contact-sheet.png`、`frames/`、`summary.md`、`pointo.json`）。
3. 如果 Pointo 的胶囊在整屏录制里看不到，告诉我一声，我改用别的方式合成。

## 3. 交给 Mac 上的 Agent 时

- 准备、启动网页、第 3 镜（在终端里跑 Claude Code）都可以让 Agent 做。
- 第 2 镜需要真人说话和用 `⇧` 画圈，建议你自己录。如果一定要 Agent 来做，就去掉说话的部分，宣传片里改用字幕。
- 录完后让 Agent 把桌面、程序坞、Finder 的设置改回原样。
