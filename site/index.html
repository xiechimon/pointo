怎么用

三步，不开窗口

  1. 1

    开始录制

    按 ⌥⇧S。Pointo 住在菜单栏，不占 Dock，不弹窗口。

  2. 2

    边说边点，按住 ⇧ 画

    直接用中文讲问题，点到哪里都会记下来。按住 ⇧ 在屏幕上画红色标注，圈出出错的地方。

  3. 3

    再按 ⌥⇧S 结束

    记录已经在剪贴板里。到任何应用按 ⌥⇧V 粘贴，或一键发进项目文件夹。

产物

压成 AI 一眼能读的目录

几分钟的录屏，AI 看不完也不需要看完。Pointo 把它压成体积小、结构固定的一个目录： 先扫一眼总览图，需要细看再取全分辨率关键帧，文字和操作按时间对齐。

  • contact-sheet.png 总览图，一张图看完全程。
  • frames/ 关键帧，标注和点击位置都画在上面。
  • summary.md 带时间的转写和操作记录。
  • pointo.json 机器可读的清单。
.pointo/captures/2026-11-14-1530/
├─ contact-sheet.png  总览图
├─ frames/            关键帧
│   ├─ 0001.png
│   └─ 0002.png
├─ summary.md         转写 + 操作记录
└─ pointo.json        清单

本地中文转写

声音留在这台 Mac 上

语音在设备上转写：Qwen3-ASR 0.6B 模型经 transcribe.cpp 在本机运行。 没有云端、没有 API Key，录音不上传。

  • 普通话、粤语、中英混说，写代码时的英文术语不会被硬翻成汉字。
  • 首次下载约 850 MB 模型，优先走 hf-mirror.com 国内镜像，之后离线可用。
  • 不需要账号，也不计费。

投递到任意项目

自动找到该去的那个项目

Pointo 按下面的顺序自动识别目标项目，识别不对就手动选：

  1. 固定项目
  2. 浏览器页面登记的目录
  3. localhost 端口所在进程的项目
  4. 终端当前目录

记录写入 <项目>/.pointo/captures/，最新一条在 .pointo/latest。 Pointo 自动把它加进 .git/info/exclude，不改你的 .gitignore。

最近用过的项目可以一键发送。每次录制也都会复制到剪贴板，⌥⇧V 粘贴到前台应用。

安装与首次打开

下载，拖进应用程序

macOS

Apple 芯片 · macOS 15 及以上

  1. 下载 Pointo-latest-arm64.dmg，把 Pointo 拖进“应用程序”。
  2. 应用未经 Apple 公证。第一次双击会被拦下：打开“系统设置 › 隐私与安全性”，在页面下方点“仍要打开”，再确认一次。
  3. 或者在终端运行一行命令直接放行： 
    xattr -dr com.apple.quarantine /Applications/Pointo.app
  4. 按提示授予屏幕录制、麦克风、辅助功能权限。

Windows（预览版）

  1. 到 Releases 页面下载 Windows 的 .zip。
  2. 解压后运行。预览版的功能和稳定性不如 macOS 版，遇到问题请提 issue。

FAQ

常见问题

我的屏幕和声音会上传吗？能离线用吗？

不会。转写在本机完成，录音不上传，记录只写到本机目录和剪贴板。转写模型首次需要联网下载一次，之后可以完全离线。

需要什么系统？

Apple 芯片（M 系列）的 Mac，macOS 15 及以上。Windows 有预览版。Intel 版 Mac 目前没有构建。

和 Scrawl 是什么关系？

Pointo 基于 kitlangton/scrawl（MIT）修改，面向中文使用：本地 Qwen3-ASR 转写、投递到任意项目、适配更多 AI 编程工具。感谢原作者。

为什么首次打开要手动放行？

公证需要付费的 Apple 开发者账号，目前没有。放行步骤见上面的“安装与首次打开”。源码全部公开，也可以自己编译。
